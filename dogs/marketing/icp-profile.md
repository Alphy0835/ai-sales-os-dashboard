# ICP Profile — Ideal Customer Profile

> Продуктовый профиль целевого пользователя. Описывает проблему, контекст работы, технический стек и требования к системе — без привязки к конкретной компании или воронке.

---

## The Problem

Отделы продаж с многоэтапными процессами и большим объёмом коммуникаций **не видят деградацию качества вовремя**. Просадка обнаруживается по выручке и прибыли — когда причинно-следственная связь уже размыта.

Корневая причина: **много точек влияния, мало инструментов для сквозного контроля в реальном времени.**

- N этапов воронки × множество типов касаний = высокий объём данных на анализ
- Руководитель в прямом контроле держит 5–10 человек; всё остальное — через подчинённых и агрегаты
- ОКК физически не покрывает весь объём коммуникаций
- Отчёты разбросаны по системам — нет единой картины качества
- Feedback даётся, но не отслеживается его применение

## Current Workflow

### Типовой технический стек ОП

| Категория | Инструменты | Что даёт | Чего не даёт |
|-----------|-------------|----------|--------------|
| **CRM** | amoCRM, Bitrix24, Salesforce, HubSpot, кастомные | Сделки, этапы, контакты, базовые метрики | Качество коммуникаций, содержание разговоров |
| **Телефония** | Mango, UIS, Asterisk, RingCentral, встроенная в CRM | Записи звонков, длительность, статус | Анализ содержания, оценка по критериям |
| **Видеосвязь** | Zoom, Google Meet, Teams, Kinescope | Записи встреч | Автоанализ, привязка к CRM без ручной работы |
| **Мессенджеры** | WhatsApp, Telegram, встроенные чаты CRM | Переписка с клиентами | Единая картина, анализ качества |
| **Отчётность** | Google Sheets, Excel, BI (Power BI, Looker), выгрузки из CRM | Кастомные метрики, сводки | Связь метрик с качеством коммуникаций |
| **База знаний** | Notion, Confluence, Google Docs, LMS | Скрипты, продукт, обучение | Контекстная подсказка в момент работы |
| **ОКК** | Ручной прослуш/просмотр, чек-листы | Экспертная оценка | Масштаб, скорость, трекинг feedback |
| **AI-инструменты** | ChatGPT, Perplexity, самописные MD-системы | Ad-hoc анализ, ответы на вопросы | Интеграция, трекинг, единый контур |

### Типовой поток данных

```
Лид ──► CRM (статус, этап)
         │
         ├── Телефония ──► запись звонка (файл / URL)
         ├── Видео ──► запись встречи
         ├── Мессенджер ──► переписка (часто вне CRM)
         └── Таблицы ──► KPI, планы, кастомные метрики

ОКК ──► выборочный просмотр ──► feedback (устно / чат / таблица)
Руководитель ──► сводка из CRM + таблицы ──► решения
```

**Разрыв:** данные есть в разных системах, но нет слоя, который связывает **содержание коммуникаций** с **метриками**, **этапом воронки** и **развитием сотрудника**.

### Иерархия управления (типовая)

```
ДП / РОП ──── весь ОП или департамент (десятки–сотни человек)
  └── РГП ──── группа тимлидов (десятки–сотни менеджеров через подчинённых)
        └── Тимлид ──── 2–10 менеджеров в прямом контроле
              └── Менеджер ──── сделки, касания, KPI
```

Система должна давать value на **каждом уровне**: тимлиду — контроль команды, РГП — агрегаты с drill-down, ДП — картина департамента и настройка процессов.

## Pain Points

### Для руководителя (любой уровень иерархии)

1. **Слепые зоны** — качество работы подчинённых вне прямого контроля не видно
2. **Feedback без трекинга** — нет системы «дали → применили / не применили»
3. **Фрагментированные данные** — CRM + таблицы + записи = нет единой картины
4. **Нет персонализации** — сложно быстро понять, что применить к конкретному клиенту на конкретном этапе
5. **Запаздывание** — просадку видят по цифрам, а не по качеству работы
6. **Масштабирование** — рост команды не пропорционален росту видимости
7. **Развитие людей** — задачи, зоны роста, темы разборов не систематизированы

### Для линейного менеджера

1. **Нет прозрачности динамики** — непонятно, где растёшь, где стагнируешь
2. **Нет контекстной подготовки** — перед касанием нет персонализированного плана
3. **Абстрактный feedback** — без конкретики и материалов для прокачки

### Для бизнеса (системный уровень)

1. **ОКК не масштабируется** — рост штата ОП ≠ пропорциональный рост ОКК
2. **Позднее обнаружение просадок** — потери до момента реакции
3. **Зависимость от конкретных людей** — экспертиза в головах, а не в системе

---

## Critical Problem

> **ОП не может системно выявлять зоны роста и прокачивать сотрудников в процессе работы — потому что нет инструмента, который связывает качество коммуникаций, метрики, этапы воронки и развитие людей в едином контуре.**

Это проблема **видимости и скорости реакции**, а не мотивации или скриптов.

---

## Current (failed) Solutions

| Решение | Что закрывает | Почему недостаточно |
|---------|---------------|---------------------|
| **CRM + отчёты** | Что произошло, базовые метрики | Не показывает как и почему |
| **ОКК (ручной)** | Экспертная оценка качества | Не масштабируется на весь объём |
| **База знаний (Notion и т.п.)** | Хранение материалов | Не связана с реальной работой и анализом |
| **Generic AI (ChatGPT и т.п.)** | Ad-hoc вопросы | Нет контекста бизнеса, нет трекинга, нет контура |
| **Самописные MD/wiki-системы** | Гибкость для одного пользователя | Не масштабируются на команду; требуют обучения |
| **Единый скрипт** | Стандартизация | Нет персонализации под клиента и этап |
| **Еженедельные разборы** | Feedback | Не покрывают объём; нет трекинга применения |

**Паттерн:** каждое решение закрывает 1–2 задачи. Нужна система, которая объединяет pipeline + анализ коммуникаций + базу знаний + развитие людей + аналитику.

## What They Actually Need

### Must Have

1. **Настраиваемый pipeline** — этапы, касания, критерии под процесс компании
2. **Анализ коммуникаций** — по правилам pipeline, с настраиваемым охватом
3. **Единый дашборд** — вместо разрозненных таблиц и выгрузок
4. **Зоны роста по сотруднику** — конкретные, привязанные к критериям
5. **Трекинг feedback** — дали → применил / не применил
6. **Сигналы просадки** — отклонения до влияния на P&L
7. **Иерархия ролей** — value на уровне тимлида, РГП, ДП

### Should Have

8. **Deal Strategy Builder** — помощь в нестандартных сделках
9. **База знаний + AI** — контекстные рекомендации из материалов компании
10. **Employee View** — личный кабинет менеджера
11. **Агрегация кастомных отчётов** — подключение существующих таблиц / BI
12. **Интеграции** — CRM, телефония, видео, мессенджеры

### Nice to Have

13. **Аттестация и чек-листы** по критериям компании
14. **Рекомендации по масштабированию** команды и структуры
15. **Прогнозирование** на основе качества работы (не только метрик CRM)

## ICP Snapshot

| Параметр | Значение |
|----------|----------|
| **Кто использует** | Руководители всех уровней (тимлид → ДП), ОКК, менеджеры |
| **Размер ОП** | От малых групп (5–10) до крупных департаментов (100–300+) |
| **Тип продаж** | B2C, B2B, смешанные; средний и высокий чек |
| **Воронка** | Настраиваемая; любое количество этапов и типов касаний |
| **Технический минимум** | CRM + записи звонков (или готовность их внедрить) |
| **Текущий контроль** | ОКК (частичный) + CRM-отчёты + таблицы + разборы |
| **Триггер внедрения** | Просадка результатов, рост штата, масштабирование ОП, замена/усиление ОКК |
