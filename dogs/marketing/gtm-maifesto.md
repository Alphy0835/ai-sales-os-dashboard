## 1. ICP (Ideal Customer Profile)

### Primary ICP — «ОП с высоким объёмом коммуникаций»

**Кто:** руководители отделов продаж, коммерческие директора, тимлиды и РГП — на любом уровне иерархии.

| | |
|---|---|
| **Размер ОП** | От малых групп до крупных департаментов (100–300+ человек) |
| **Продажи** | B2C, B2B, смешанные; средний и высокий чек |
| **Pipeline** | Многоэтапный, настраиваемый; звонки + видео + переписка |
| **Контроль** | ОКК (частичный или отсутствует), CRM, таблицы, разрозненные отчёты |
| **Боль** | Нет сквозной видимости качества; просадки видны поздно |
| **Триггер** | Просадка результатов, рост штата, масштабирование, усиление контроля качества |

### Secondary ICP — «Компании с большим потоком клиентов»

- Высокий объём входящих / исходящих касаний
- Много менеджеров, много параллельных сделок
- Критична стандартизация качества при масштабе
- Ценят единый контур: pipeline + анализ + развитие

### Anti-ICP

- Нет записи коммуникаций и нет планов её внедрять
- Нет CRM / систем учёта сделок
- Полностью автоматизированные продажи без человеческих касаний (нет смысла в анализе)

## 2. Value Proposition

### One-liner

> **AI Sales OS Dashboard — система, которая анализирует коммуникации отдела продаж, находит зоны просадки раньше, чем это скажется на прибыли, и помогает развивать команду в процессе работы.**

### Value Pillars

**1. Сквозная видимость качества**
- AI-анализ коммуникаций по правилам настраиваемого pipeline
- Единый дашборд вместо разрозненных отчётов
- Drill-down от департамента до конкретного касания

**2. Раннее обнаружение просадок**
- Система фиксирует отклонения в качестве и метриках **раньше**, чем они проявятся в P&L
- Сигналы по контуру руководителя (тимлид / РГП / ДП)

**3. Развитие людей в процессе работы**
- Профиль сотрудника: сильные стороны, зоны роста, динамика
- Трекинг feedback: дали → применил / не применил
- Рекомендации из базы знаний компании

**4. Персонализация под процесс и клиента**
- Pipeline Builder — воронка под процесс компании, не наоборот
- AI адаптирует рекомендации под этап, тип касания и профиль клиента

**5. Масштабирование без пропорционального роста ОКК**
- Автоматический анализ по правилам вместо ручного прослушивания
- Единый стандарт качества на любом размере ОП

### Positioning Statement

```
Для отделов продаж с большим объёмом коммуникаций,
которые не могут контролировать качество работы на всём объёme,

AI Sales OS Dashboard — операционная система продаж,

которая находит зоны просадки и помогает их устранить
до того, как это повлияет на прибыль.

В отличие от CRM (показывает «что») и ОКК (не масштабируется),
мы даём: pipeline + анализ качества + развитие людей + сигналы — в одном контуре.
```

## 3. Ключевые продуктовые принципы

1. **Pipeline — конфигурация, не константа.** Каждый клиент настраивает свою воронку.
2. **Value на каждом уровне иерархии.** Тимлид, РГП, ДП — разные дашборды, один источник данных.
3. **Раньше P&L.** Система ищет отклонения в качестве, а не ждёт падения выручки.
4. **Feedback loop.** Дали рекомендацию → отследили применение → измерили результат.
5. **База знаний — контекст, не архив.** AI использует материалы компании в момент анализа и рекомендаций.
