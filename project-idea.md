# AI Sales OS Dashboard

## The Idea

**AI Sales OS Dashboard** — операционная система для отделов продаж. Продукт закрывает разрыв между CRM (что произошло) и реальным качеством работы (как это произошло и почему).

Система автоматически анализирует коммуникации сотрудников — звонки, сообщения, видеовстречи — связывает их с внутренней базой знаний, кастомными отчётами и профилем целевой аудитории. На выходе руководитель получает не просто метрики, а **действия**: где началась просадка, у кого какая зона роста, что применить с конкретным клиентом, кого и чем прокачать.

Два уровня ценности:

| Роль | Что получает |
|------|--------------|
| **Руководитель (любой уровень иерархии)** | Картина своего контура, сигналы просадки до влияния на прибыль, план развития подчинённых |
| **Линейный менеджер** | Личная динамика, зоны роста, персонализированные рекомендации |

## The Flow

Как пользователь работает с продуктом — от первого входа до получения результата.

### Первый запуск (онбординг)

```
Вход → Настройка pipeline → База знаний → Источники данных → Готово
```

1. **Вход** — регистрация, создание рабочего пространства, приглашение команды
2. **Pipeline** — настройка этапов воронки, типов касаний и критериев качества под процесс компании
3. **База знаний** — загрузка материалов: продукт, скрипты, возражения, кейсы, описание ЦА
4. **Источники данных** — подключение CRM / телефонии или ручная загрузка записей и отчётов
5. **Первый анализ** — система обрабатывает данные, пользователь видит начальный дашборд

### Ежедневный цикл

```
Данные поступают → AI анализирует → Открыл → Получил → Действуешь
```

1. **Данные поступают** — автоматически (интеграции) или вручную (загрузка файлов, импорт отчётов)
2. **AI анализирует** — транскрипция, оценка по критериям pipeline, связка с базой знаний
3. **Открыл** — дашборд, карточка сотрудника, карточка сделки или свой профиль (Employee View)
4. **Получил** — оценки качества, зоны роста, сигналы просадки, рекомендации, сводки
5. **Действуешь** — feedback, задачи, подготовка к касанию, разбор, корректировка pipeline

### Сценарий: подготовка к касанию

1. Менеджер открывает карточку клиента / сделки
2. Система подтягивает историю касаний + текущий этап pipeline + профиль клиента
3. AI предлагает план на основе базы знаний, этапа воронки и контекста переписки
4. После касания — автоматический разбор: соответствие критериям этапа, применение прошлого feedback

### Сценарий: обнаружение просадки

1. Система агрегирует кастомные отчёты и метрики качества
2. AI выявляет отклонения от нормы **раньше**, чем это отразится на прибыли
3. Руководитель получает сигнал + контекст + рекомендуемые действия (разбор, корректировка процесса, перераспределение)

### Сценарий: сложная сделка

1. Руководитель или менеджер не понимает, как двигать сделку дальше
2. **Deal Strategy Builder** — анализ всех касаний по сделке, профиль клиента, кейсы из базы знаний
3. Предлагает: аргументы, работа с возражениями, следующий шаг, риски

## Why It Matters

| Без системы | С AI Sales OS |
|-------------|---------------|
| ОКК покрывает малую долю коммуникаций | Анализ по правилам pipeline — настраиваемый охват |
| Просадка видна по выручке / прибыли | Отклонения в качестве и метриках — до влияния на P&L |
| Feedback не отслеживается | Трекинг: дали → применил / не применил |
| Один скрипт на всех | AI адаптирует под клиента, этап и контекст |
| Задачи по развитию — в голове руководителя | Профиль развития каждого сотрудника в системе |
| Отчёты фрагментированы | Единый дашборд + AI-сводка по контуру |
| Масштаб = пропорциональный рост ОКК | Масштаб = подключение контура к системе |

**Критическая проблема:** в ОП деградация качества и просадки обнаруживаются с запаздыванием — когда уже видно в цифрах. Нужна система, которая работает **в процессе**.

## How It Works

### Ядро системы (модули)

**0. Pipeline Builder** *(конфигурация)*
- Настраиваемая воронка: этапы, типы касаний, критерии качества, playbooks — под процесс компании, не зашито в продукт
- Маппинг этапов на статусы CRM
- Правила автоматического анализа по этапам

**1. Communication Intelligence**
- Транскрипция и анализ звонков
- Анализ видеовстреч
- Анализ переписки (сообщения, email)
- Оценка качества по критериям, заданным в Pipeline Builder

**2. Knowledge Engine**
- Внутренняя база знаний: продукт, ЦА, скрипты, возражения, кейсы
- AI использует базу при анализе и рекомендациях
- Персонализация под клиента и этап pipeline

**3. People Development**
- Профиль сотрудника: сильные стороны, зоны роста, история feedback
- Чек-листы и аттестация по критериям руководителя
- Рекомендации по материалам из базы знаний
- Трекинг динамики: растёт / стагнирует / проседает

**4. Deal Strategy Builder**
- Анализ всех касаний по конкретной сделке
- Стратегия с учётом профиля клиента, этапа и истории
- Сценарии для нестандартных ситуаций

**5. Analytics Hub**
- Агрегация кастомных отчётов из разных источников
- AI-сводка по контуру руководителя
- Сигналы при отклонении от нормы

**6. Manager Command Center**
- Дашборд по уровню иерархии (тимлид / РГП / ДП)
- Очередь действий: с кем разобрать, кому что поставить
- Drill-down: от агрегата отдела до конкретного касания

### Employee View

- Личный дашборд: динамика, прогресс по навыкам
- Конкретные рекомендации на период
- История feedback и статус применения
- Подготовка к касаниям с AI-подсказками

### Ролевая модель доступа

| Роль | Видит | Действует |
|------|-------|-----------|
| Менеджер | Свои сделки, свой профиль | Готовится к касаниям, видит feedback |
| Тимлид | Своя команда (5–10 чел) | Разборы, задачи, оценка |
| РГП | Группы тимлидов | Агрегаты, drill-down, развитие РГП-контура |
| ДП / РОП | Весь ОП или свой департамент | Pipeline config, критерии, стратегия |
| ОКК | Аналитика качества по правилам | Верификация, калибровка критериев |
| Админ | Настройки системы, интеграции | Pipeline Builder, база знаний, пользователи |

## MVP vs Полная версия

### MVP (первая итерация)
- Pipeline Builder (базовая настройка этапов и критериев)
- Загрузка / интеграция записей звонков
- AI-анализ качества по критериям
- База знаний (загрузка документов)
- Дашборд руководителя: качество команды + зоны роста
- Профиль сотрудника с рекомендациями

### V2
- Анализ видеовстреч и переписки
- Deal Strategy Builder
- Агрегация кастомных отчётов
- Employee View
- Сигналы просадки по контуру

### V3
- Полная иерархия (тимлид → РГП → ДП)
- Аттестация и чек-листы
- Интеграции с CRM, телефонией, мессенджерами
- Масштабирование: рекомендации по развитию и структуре команды
