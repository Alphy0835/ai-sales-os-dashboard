# Flow: Ежедневный цикл

← [project-idea.md](../../project-idea.md)

```
Данные поступают → AI анализирует → Открыл → Получил → Действуешь
```

| # | Шаг | MVP | Post-MVP |
|---|-----|-----|----------|
| 1 | **Данные поступают** | Ручная загрузка audio/transcript | Авто-импорт из CRM / телефонии |
| 2 | **AI анализирует** | Транскрипция + оценка по criteria + knowledge base | + видео, переписка |
| 3 | **Открыл** | Manager Card, Employee Profile, Evaluation Detail | + Deal card, Employee View |
| 4 | **Получил** | Score, growth zones, recommendations | + алерты, deal strategy |
| 5 | **Действуешь** | Просмотр, разбор | + feedback, задачи, pipeline config |
