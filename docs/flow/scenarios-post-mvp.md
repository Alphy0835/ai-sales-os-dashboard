# Flow: Сценарии (Post-MVP)

> Не входят в MVP. Зафиксированы для roadmap.

---

## Подготовка к касанию

1. Менеджер открывает карточку клиента / сделки
2. Система подтягивает историю касаний + stage pipeline + профиль клиента
3. AI предлагает план на основе knowledge base и контекста
4. После касания — авторазбор: criteria + применение прошлого feedback

---

## Обнаружение просадки

1. Агрегация отчётов и метрик качества
2. AI выявляет отклонения **раньше**, чем это отразится на P&L
3. Руководитель получает сигнал + контекст + рекомендуемые действия

---

## Сложная сделка (Deal Strategy Builder)

1. Непонятно, как двигать сделку дальше
2. AI анализирует все касания + профиль клиента + кейсы из базы
3. Выдаёт: аргументы, возражения, next step, риски
