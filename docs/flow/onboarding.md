# Flow: Онбординг

← [project-idea.md](../../project-idea.md)

```
Вход → Pipeline → База знаний → Источники данных → Первый анализ
```

| # | Шаг | Действие |
|---|-----|----------|
| 1 | **Вход** | Регистрация, создание workspace, приглашение команды |
| 2 | **Pipeline** | Этапы воронки, типы касаний, критерии качества |
| 3 | **База знаний** | Продукт, скрипты, возражения, кейсы, ЦА |
| 4 | **Источники данных** | CRM / телефония *(post-MVP)* или ручная загрузка |
| 5 | **Первый анализ** | Обработка данных → начальный дашборд |

**MVP:** шаги 1–3 + ручная загрузка звонка (шаг 4 без интеграций).
