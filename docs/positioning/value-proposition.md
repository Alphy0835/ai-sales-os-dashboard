# Positioning: Value Proposition

← [gtm-maifesto.md](../marketing/gtm-maifesto.md)

---

## One-liner

> AI Sales OS Dashboard — анализирует коммуникации ОП, находит просадки до P&L, развивает команду в процессе работы.

---

## Value Pillars

**1. Сквозная видимость** — AI по pipeline rules, единый дашборд, drill-down

**2. Раннее обнаружение** — отклонения в качестве раньше P&L

**3. Развитие людей** — profile, feedback loop, recommendations из knowledge base

**4. Персонализация** — Pipeline Builder + AI под stage и клиента

**5. Масштаб без роста ОКК** — автоанализ вместо ручного прослушивания

---

## Positioning Statement

```
Для ОП с большим объёмом коммуникаций,
которые не контролируют качество на всём объёme,

AI Sales OS Dashboard — операционная система продаж,

которая находит просадки до влияния на прибыль.

Vs CRM (что) и ОКК (не масштабируется):
pipeline + качество + развитие + сигналы — в одном контуре.
```
