## Принципы

1. **Pipeline — конфигурация**, не константа
2. **Value на каждом уровне иерархии** — разные дашборды, один источник
3. **Раньше P&L** — отклонения в качестве, не ждём выручку
4. **Feedback loop** — рекомендация → применение → результат
5. **Knowledge base — контекст**, не архив
