# Positioning: ICP Segments

---

## Primary — «ОП с высоким объёмом коммуникаций»

**Кто:** РОП, комдир, тимлиды, РГП.

| | |
|---|---|
| Размер ОП | Малые группы → 100–300+ |
| Продажи | B2C/B2B, средний+ чек |
| Pipeline | Многоэтапный, настраиваемый |
| Контроль | ОКК (частичный), CRM, таблицы |
| Боль | Нет сквозной видимости качества |
| Триггер | Просадка, рост штата, масштабирование |

## Secondary — «Большой поток клиентов»

- Высокий объём касаний
- Много менеджеров, параллельных сделок
- Стандартизация качества при масштабе

## Anti-ICP

- Нет записи коммуникаций и планов внедрить
- Нет CRM
- Полностью автоматизированные продажи без human touch
