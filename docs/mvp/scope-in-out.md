# MVP: In / Out Scope

← [mvp-scope.md](../project/features/mvp-scope.md)

---

## In scope

| # | Capability | Описание |
|---|------------|----------|
| 1 | **Workspace** | Рабочее пространство компании |
| 2 | **Pipeline Builder** | Stages, touchpoint types |
| 3 | **Quality Criteria** | CRUD, привязка к stage + type |
| 4 | **Knowledge Base** | TXT, MD, PDF* |
| 5 | **Employees** | Список сотрудников |
| 6 | **Call Upload** | Audio **или** transcript |
| 7 | **AI Evaluation** | Транскрипция + analysis |
| 8 | **Evaluation Result** | score, summary, strengths, weaknesses, recommendations |
| 9 | **Employee Profile** | History, growth zones |
| 10 | **Manager Card** | Список, последние оценки, drill-down |

\* PDF — если feasible; иначе TXT/MD.

---

## Out of scope

- Интеграции CRM / телефония / мессенджеры
- Автоимпорт звонков
- Видео, переписка
- Deal Strategy Builder
- Employee View
- Алерты / сигналы просадки
- Иерархия ролей (тимлид → РГП → ДП)
- Ручной feedback с трекингом
- Аттестация, чек-листы
- BI / внешние отчёты
- Multi-tenant
- Биллинг
