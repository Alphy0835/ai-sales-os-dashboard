# MVP: Acceptance Criteria

← [mvp-scope.md](../../dogs/progect/feauters/mvp-scope.md) · [demo-scenario-1.md](../../dogs/progect/feauters/demo-scenario-1.md)

MVP готов, когда все пункты выполнены.

---

## Upload & Input

- [ ] **AC-1.** Upload audio (MP3/WAV/M4A) **или** transcript (text/file).
- [ ] **AC-2.** Pipeline ≥1 stage + ≥1 quality criterion.
- [ ] **AC-3.** ≥1 document в knowledge base.
- [ ] **AC-4.** Employee создан и выбирается при upload.

## Processing

- [ ] **AC-5.** Auto-transcribe audio, если нет transcript.
- [ ] **AC-6.** Touchpoint → employee + stage.
- [ ] **AC-7.** Analysis по criteria выбранного stage.
- [ ] **AC-8.** Knowledge base используется как контекст.

## Output

- [ ] **AC-9.** Evaluation: score, summary, strengths, weaknesses, recommendations.
- [ ] **AC-10.** Strength/weakness привязан к criterion (или «общий»).

## Employee & Manager

- [ ] **AC-11.** Employee Profile — история evaluations.
- [ ] **AC-12.** Growth zones при ≥2 evaluations с повторяющимися weaknesses.
- [ ] **AC-13.** Manager Card — список, last score, drill-down.

## End-to-end

- [ ] **AC-14.** Demo Scenario 1 без костылей.
- [ ] **AC-15.** Upload → evaluation <5 мин (звонок 10–15 мин).
