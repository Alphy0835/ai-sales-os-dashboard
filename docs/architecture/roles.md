# Architecture: Роли и доступ

← [project-idea.md](../../project-idea.md)

---

## MVP

| Роль | Видит | Действует |
|------|-------|-----------|
| **Admin** | Всё в workspace | Pipeline, criteria, knowledge base, users |
| **Manager** | Команда, evaluations, profiles | Просмотр, разбор *(ручной feedback — post-MVP)* |

Employee в MVP — объект оценки, без отдельного UI.

---

## Post-MVP

| Роль | Видит | Действует |
|------|-------|-----------|
| **Менеджер** | Свои сделки, свой профиль | Подготовка к касаниям, feedback |
| **Тимлид** | Команда 5–10 чел | Разборы, задачи |
| **РГП** | Группы тимлидов | Агрегаты, drill-down |
| **ДП / РОП** | Департамент / ОП | Pipeline config, стратегия |
| **ОКК** | Аналитика качества | Верификация, калибровка criteria |
