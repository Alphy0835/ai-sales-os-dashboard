## MVP

### Pipeline Builder *(конфигурация)*
- Настраиваемая воронка: stages, touchpoint types, criteria, playbooks
- Маппинг на CRM *(post-MVP)*
- Правила автоанализа по stages

### Communication Intelligence
- Транскрипция и анализ звонков *(MVP)*
- Видеовстречи, переписка *(post-MVP)*
- Оценка по criteria из Pipeline Builder

### Knowledge Engine
- База знаний: продукт, ЦА, скрипты, возражения, кейсы
- AI-контекст при analysis и recommendations

### People Development
- Employee Profile: strengths, growth zones, history
- Чек-листы, аттестация *(post-MVP)*
- Трекинг динамики: растёт / стагнирует / проседает

---

## Post-MVP

### Deal Strategy Builder
- Анализ всех касаний по сделке → стратегия, next step, риски

### Analytics Hub
- Агрегация кастомных отчётов, AI-сводка, сигналы

### Manager Command Center
- Дашборд по иерархии, очередь действий, drill-down

### Employee View
- Личный кабинет менеджера: динамика, подготовка к касаниям
