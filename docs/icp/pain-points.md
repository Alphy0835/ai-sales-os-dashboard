## Руководитель

1. **Слепые зоны** — качество вне прямого контроля не видно
2. **Feedback без трекинга** — нет «дали → применили»
3. **Фрагментированные данные** — CRM + таблицы + записи
4. **Нет персонализации** — что применить к клиенту на этапе
5. **Запаздывание** — просадка по цифрам, не по качеству
6. **Масштабирование** — рост команды ≠ рост видимости
7. **Развитие людей** — задачи и зоны роста не систематизированы

## Линейный менеджер

1. Нет прозрачности динамики
2. Нет контекстной подготовки к касанию
3. Абстрактный feedback без материалов

## Бизнес

1. ОКК не масштабируется
2. Позднее обнаружение просадок
3. Экспертиза в головах, не в системе
