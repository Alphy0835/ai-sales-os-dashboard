## Типовой технический стек ОП

| Категория | Инструменты | Даёт | Не даёт |
|-----------|-------------|------|---------|
| **CRM** | amoCRM, Bitrix24, Salesforce, HubSpot | Сделки, этапы, метрики | Качество коммуникаций |
| **Телефония** | Mango, UIS, Asterisk, RingCentral | Записи, длительность | Анализ содержания |
| **Видео** | Zoom, Meet, Teams, Kinescope | Записи встреч | Автоанализ |
| **Мессенджеры** | WhatsApp, Telegram, CRM-чаты | Переписка | Единая картина |
| **Отчётность** | Sheets, Excel, BI | KPI, сводки | Связь с качеством |
| **База знаний** | Notion, Confluence, Docs | Скрипты, обучение | Контекст в момент работы |
| **ОКК** | Ручной просмотр | Экспертиза | Масштаб, трекинг |
| **AI** | ChatGPT, Perplexity, MD-системы | Ad-hoc анализ | Интеграция, контур |

## Поток данных (as-is)

```
Лид → CRM
       ├── Телефония → запись
       ├── Видео → запись
       ├── Мессенджер → переписка
       └── Таблицы → KPI

ОКК → выборочный просмотр → feedback
Руководитель → CRM + таблицы → решения
```

**Разрыв:** нет слоя, связывающего **содержание коммуникаций** + **метрики** + **stage** + **развитие сотрудника**.

## Иерархия управления

```
ДП / РОП ──── департамент (десятки–сотни)
  └── РГП ──── группы тимлидов
        └── Тимлид ──── 2–10 менеджеров
              └── Менеджер
```

Value на каждом уровне: тимлид — команда, РГП — агрегаты + drill-down, ДП — департамент + config.
