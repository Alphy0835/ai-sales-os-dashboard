## Must Have

1. Настраиваемый pipeline
2. Анализ коммуникаций по правилам pipeline
3. Единый дашборд
4. Зоны роста по сотруднику
5. Трекинг feedback
6. Сигналы просадки до P&L
7. Иерархия ролей

## Should Have

8. Deal Strategy Builder
9. Knowledge base + AI
10. Employee View
11. Агрегация кастомных отчётов
12. Интеграции

## Nice to Have

13. Аттестация, чек-листы
14. Рекомендации по масштабированию
15. Прогнозирование по качеству работы
