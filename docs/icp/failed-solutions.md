# ICP: Failed Solutions

← [icp-profile.md](../marketing/icp-profile.md)

| Решение | Закрывает | Недостаточно |
|---------|-----------|--------------|
| **CRM + отчёты** | Что произошло | Не как и почему |
| **ОКК (ручной)** | Экспертная оценка | Не масштабируется |
| **База знаний** | Хранение | Не связана с работой |
| **Generic AI** | Ad-hoc вопросы | Нет контекста, трекинга |
| **MD/wiki-системы** | Гибкость | Не масштабируются на команду |
| **Единый скрипт** | Стандартизация | Нет персонализации |
| **Еженедельные разборы** | Feedback | Не покрывают объём |

**Паттерн:** каждое решение — 1–2 задачи. Нужна система: pipeline + analysis + knowledge + development + analytics.
