# Glossary: Entities

← [product-glossary.md](../../product-glossary.md)

| Термин | Определение |
|--------|-------------|
| **Call Recording** | Аудиофайл для транскрипции и analysis. |
| **Transcript** | Текст звонка. Upload или auto из audio. |
| **Knowledge Base** | Документы workspace для AI-контекста. |
| **Knowledge Document** | Файл в KB: PDF, MD, TXT, DOCX. |
| **Employee Profile** | Карточка: history, score, growth zones. |
| **Deal** | Сделка. MVP: опционально через CSV. |
| **Manager Summary** | Сводка для руководителя без детального разбора. |
