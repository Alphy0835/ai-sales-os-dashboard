# Glossary: Org & Access

← [product-glossary.md](../../product-glossary.md)

| Термин | Определение |
|--------|-------------|
| **Workspace** | Рабочее пространство компании. Изолированный контур: pipeline, KB, сотрудники, оценки. |
| **Admin** | Настройка workspace: pipeline, criteria, KB, users. |
| **Manager** | Руководитель. Карточки подчинённых, summary, growth zones команды. |
| **Employee** | Sales-менеджер. В MVP — объект оценки, без отдельного UI. |
