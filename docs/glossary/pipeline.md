# Glossary: Pipeline

← [product-glossary.md](../../product-glossary.md)

| Термин | Определение |
|--------|-------------|
| **Pipeline** | Настраиваемый набор этапов продаж. Конфигурируется в workspace. |
| **Stage** | Этап pipeline: название, описание, touchpoint types, criteria. |
| **Touchpoint** | Единичное касание: звонок, встреча, переписка. |
| **Touchpoint Type** | `call`, `meeting`, `message`, `email`, `other`. |
| **Playbook** | Скрипт / сценарий для stage. *(Post-MVP)* |
