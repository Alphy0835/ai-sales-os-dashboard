# Glossary: Evaluation

← [product-glossary.md](../../product-glossary.md)

| Термин | Определение |
|--------|-------------|
| **Quality Criterion** | Правило оценки. Название, описание, шкала, привязка к stage + type. |
| **Evaluation** | Результат AI-анализа touchpoint. |
| **Score** | Итоговая оценка по criteria. |
| **Strength** | Сильная сторона в touchpoint или паттерн по сотруднику. |
| **Weakness / Violation** | Нарушение criterion. |
| **Growth Zone** | Зона роста из повторяющихся weaknesses. |
| **Recommendation** | Конкретное действие для сотрудника / руководителя. |
| **Feedback** | Рекомендация руководителя. MVP: AI-recommendations; ручной — post-MVP. |
