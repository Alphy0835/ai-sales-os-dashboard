# Typography

Inter primary. Clean dashboard hierarchy, no decorative fonts.

| Style | Size / Line / Weight | Use |
|---|---|---|
| Page title | 32px / 40px / 700 | Z-TOPBAR / page header |
| Main KPI | 40–48px / 1.1 / 700 | hero metrics |
| Section title | 18–22px / 28px / 600 | card groups |
| Card title | 15–18px / 24px / 600 | card headers |
| Body | 14–15px / 22px / 400 | content |
| Meta | 11–13px / 16px / 400 | captions, table meta |

Font stack: `'Inter', 'Segoe UI', system-ui, sans-serif`

Rules: bold clean numbers; minimal uppercase; readable on dark cards.
