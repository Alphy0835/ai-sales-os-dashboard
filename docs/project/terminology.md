# Terminology

Базовые термины проекта. При расхождении формулировок в других документах приоритет у этого файла.

## People and Access

| Термин | Определение | Где используется |
|---|---|---|
| Пользователь | Тот, кто использует систему на User Level: руководитель, сотрудник и другие роли заказчика с выданными правами | product, frontend, backend, security |
| Интегратор | Тот, кто устанавливает, настраивает и контролирует работу и стабильность системы на Integration Level | operations, backend, security |
| Руководитель | Пользователь с правами контроля подразделения: дашборды, разборы, задачи, настройки, AI-аналитика | product, frontend |
| Сотрудник | Пользователь с правами работы над своими показателями и задачами; доступ к функциям не шире, чем у выдавшего права руководителя | product, frontend, security |
| Подразделение | Организационная единица внутри ОП, по которой агрегируются показатели и права доступа | product, backend |
| Право доступа | Разрешение на модуль или материал в режиме none / view / edit / run / use | security, product |
| Scope | Область видимости пользователя: подразделения, сотрудники и материалы, доступные по роли | security, backend |

## System Levels

| Термин | Определение | Где используется |
|---|---|---|
| Integration Level | Уровень системы для интеграторов и эксплуатации | architecture, operations |
| User Level | Уровень системы для пользователей заказчика | architecture, product |

## Product Domain

| Термин | Определение | Где используется |
|---|---|---|
| Дашборд | Главный экран с агрегированными показателями: у руководителя — по подразделению, у сотрудника — личный | product, frontend |
| Норма | Плановый или эталонный показатель, относительно которого считается отставание | product, backend |
| Разбор | Сессия обсуждения работы сотрудника с фиксацией комментариев и задач | product, frontend |
| Задача | Поручение сотруднику, поставленное руководителем в рамках разбора | product, frontend |
| Клиент к разбору | Клиент, по которому система рекомендует провести разбор с сотрудником, с кратким обоснованием | product, AI |
| Критерий оценки | Правило и описание, по которому AI оценивает качество общения на этапе воронки | product, AI, backend |
| Транскрипция | Текстовая расшифровка аудио/видео записи общения с клиентом | backend, AI |
| Канвас | Визуальный AI-отчёт с ключевыми метриками, динамикой и рекомендациями | product, frontend, AI |

## AI and Knowledge

| Термин | Определение | Где используется |
|---|---|---|
| База знаний | Хранилище материалов компании: продукты, отработки, инфоповоды, кейсы и другие знания для AI | product, backend, AI |
| RAG | Retrieval-Augmented Generation: AI-ответы с опорой на материалы базы знаний и контекст бизнеса | architecture, AI, backend |
| AI-аналитика | Запрос и получение AI-отчётов по качеству, динамике и рекомендациям по сотруднику или подразделению | product, frontend, AI |
| AI-агент | Диалоговый помощник для руководителя и сотрудника с доступом к RAG и рабочему контексту | product, frontend, AI |
| Кастомный отчёт | Отчёт, описанный пользователем простым языком и преобразованный системой в структурированный AI-запрос | product, AI |

## Integrations

| Термин | Определение | Где используется |
|---|---|---|
| CRM | Внешняя система учёта клиентов и сделок, источник показателей и контекста | architecture, integrations |
| Телефония | Источник записей звонков и данных по коммуникациям | architecture, integrations |
