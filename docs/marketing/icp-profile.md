# ICP Profile

> Навигация: [README.md](../../README.md) · Продукт: [project-idea.md](../../project-idea.md)

Профиль целевого пользователя — без привязки к конкретной компании или воронке.

---

## Summary

| | |
|---|---|
| **Кто** | Руководители (тимлид → ДП), ОКК, менеджеры |
| **Размер ОП** | 5–10 до 100–300+ человек |
| **Продажи** | B2C / B2B, средний и высокий чек |
| **Боль** | Нет сквозной видимости качества; просадки поздно |
| **Минимум** | CRM + записи звонков (или готовность внедрить) |

**Critical problem:** нет инструмента, который связывает качество коммуникаций, метрики, pipeline и развитие людей в одном контуре.
