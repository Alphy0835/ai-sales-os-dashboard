## Правила работы с документацией
— Все файлы должны иметь понятные названия и находится в структуре соответствующей типу документации
— Взаимосвязанные файлы как в рамках одной структуры так и в рамках разных структур должны иметь взаимные ссылки на конкретные описания в других файлах
— Если в одном из файлов уже описан процес или принцип, нельзя заново описывать его слово в слово, обязательно должна быть ссылка на файл где это расписано детально, а в текущем файле лишь краткая суть что используется
— Любой документ *.md в папке docs и вложенных в нее должен иметь паспорт в хедере:
